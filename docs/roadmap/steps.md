# Roadmap steps

Ordered. Each step becomes a folder under `docs/changes/` when work starts (see `changes/README.md`). Estimates are rough and assume ~15 hours a week. Keep applying for jobs in parallel.

Build the full app (or nearly) before giving it to friends on the private instance. Fast word lookup must be in place before anyone besides the developer uses it. Public-facing compliance work applies only to the demo (D-038): `roadmap/before-demo.md`.
