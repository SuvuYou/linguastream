# Unlawful sources (D-036)

- The private instance warns on videos in YouTube's Music category. The public edition, if revived, refuses them.
- A reported video's ID goes on a blocklist that every deployment checks before processing; the private instance also deletes stored copies of it. Lookup by video ID only, never by reading text.
- Terms: only videos the user may lawfully use, for private study.
- **Uploads (D-040, postponed D-066):** the user's own lawfully obtained files only. Pirated downloads and rips that break copy protection are not covered by the private-copy exception; anything reported or known to be unlawful is deleted.
